# GASAN · Landing page

Site institucional da **GASAN**, revendedora de materiais de construção que vende um pouco de tudo.
O nome vem das iniciais dos patriarcas e matriarcas da família.

## Estrutura

```
index.html              Página única com todas as seções
css/styles.css          Estilos (cores provisórias em :root)
js/main.js              Menu mobile e ano no rodapé
assets/logo-gasan*.png  Logo oficial (colorido e versão branca) e ícones
```

Seções: topo (hero), sobre a empresa, produtos (materiais de construção + variedades),
diferenciais, contato e localização, rodapé.

## Como visualizar

Abra o `index.html` no navegador. Não precisa de build nem de instalação.
